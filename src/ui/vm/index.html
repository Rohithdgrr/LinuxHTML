BEFORE YOU BEGIN

A little note about this VM.

This experimental VM uses an upstream Buildroot 2024.05.2 image with Linux 6.8.12, not the planned Alpine Linux. This image is not maintained by LinuxHTML and should not be used for sensitive workloads.

The browser sandbox is not a security guarantee. Run only trusted code. No external networking relay is configured. Guest changes are lost on reload unless you explicitly save and restore an experimental VM checkpoint. Checkpoints are unencrypted and can be evicted; they are not a backup. Files explicitly saved locally can be cleared or evicted by the browser.

AboutLinuxHTML OS
A BROWSER-BASED WORKSPACE

Made for curious minds.

LinuxHTML OS is an early preview of a web desktop with an experimental Linux VM. It runs inside your browser, not as your computer’s operating system.

Local files may be evicted or cleared. Export important work. The Linux guest is outdated and not intended for sensitive workloads.
